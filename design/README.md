# Phase 1: theme concepts

`concepts.html` shows five looks for Learning AI Auto, each with its app icon, the Home screen,
a lesson mid-exercise, and the laptop workflow builder. Open it in a browser.

`icons/` holds each concept's icon as SVG plus 512 / 192 / 180 px PNGs.
Re-export after editing `window.ICONS` in `concepts.html`: `node design/render-icons.mjs`.

The chosen concept becomes the app's design system in Phase 2; the rest get deleted.
